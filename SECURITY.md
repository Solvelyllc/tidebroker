# Security Policy

Tidebroker handles identity-bound access to external credentials. Please do not
open a public issue for suspected vulnerabilities, exposed credentials, or
deployment-specific security information.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature for this repository:

1. Open the repository's **Security** tab.
2. Select **Advisories**.
3. Select **Report a vulnerability**.

Include the affected version, security boundary, reproduction steps, and impact.
Do not include live credentials, authorization codes, refresh tokens, personal
data, or production configuration.

We will acknowledge a report as soon as practical, investigate it privately,
and coordinate disclosure and remediation with the reporter.

## Supported versions

Until the first public release, only the latest commit on the default branch is
supported. After publication, this file will list supported release lines.
